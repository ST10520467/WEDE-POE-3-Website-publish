* **Goal 1:** Allow customers to order items online for catering or just orders.

* **Goal 3:**  Sell items online to increase profits for the business.
* **Goal 4:** Is the website to have easy navigation so the customers don't get frustrated at the website. We want the website to be simple and easy to use.
* **Objective:** An objective of the website is to a allow to customers to enquiry for catering, this will increase Whole bakery overall total profit.
* **Objective:** Another objective is to allow customers to see how they can contact Whole Bakery.

* **Feature 2:**  About us- This page tells users of the website what whole bakery do and what they about. (e.g. what Whole Bakery do)
* **Feature 3:**  Contact page- This shows users how to get in touch with Whole Bakery.
* **Feature 4:** Products Page-This page is all the items Whole Bakery make and sell.
* **Feature 5:** Enquiry Page-This page is where customers can enquiry catering orders provided by Wole Bakery.
